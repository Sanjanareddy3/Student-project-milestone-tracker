Workflow rules

  • Required project, title, owner, due date and deliverable.
  • Duplicate project + milestone + owner combinations are blocked.
  • Only the Faculty Supervisor demo role can approve or request revisions.
  • Only submitted or revision-required milestones can be reviewed.
  • Overdue is derived from the due date and current status.
  • Failures show a message; the app attempts to preserve existing data.

What this prototype does not do

It does not provide real accounts, server-side access control, email reminders, file uploads, cloud backup or official college integration. Browser local storage is suitable only for a demo.

Suggested report wording: “The baseline and volumes in this prototype are hypothetical assumptions used to demonstrate the proposed workflow. No actual college observations or measured time savings are claimed.”
