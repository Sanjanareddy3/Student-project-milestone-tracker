## Student Project Milestone Tracker

This repository contains my HKAIVERSE Round 2 assignment, covering **Task 1: Student Project Milestone Tracker** and **Task 2: Curriculum Analysis and Comparison**.

The work includes an interactive HTML prototype, testing documentation, curriculum analysis, job-description research, AI-related exercises, and an interactive curriculum comparison webpage.

## Repository Overview

- `task-1/` — Student Project Milestone Tracker prototype, reports, and testing evidence.
- `task-2/` — Curriculum inventory, recommendations, credit comparison, job-description analysis, AI exercise log, capstone alignment, and interactive webpage.

## Task 1: Student Project Milestone Tracker

### Objective

Develop a prototype to help students track project milestones, monitor progress, and organize project-related activities.

### Main Features

- Interactive student project milestone tracker interface.
- Project and milestone tracking prototype.
- Basic milestone status and progress management.
- Role selection for demonstrating the interface.
- Manual browser testing with documented results.

**Note:** The prototype is a demonstration. Role selection does not provide real authentication or authorization.

## Task 2: Curriculum Analysis and Comparison

### Objective

Analyze the Computer Science and Engineering curriculum in relation to current industry requirements and emerging technology trends, and recommend improvements for future career readiness.

The analysis considers my regular B.Tech CSE program at ICFAI University, Hyderabad, with admission in 2023.

### Main Activities

- Organizing the available curriculum information into a semester-wise inventory.
- Reviewing core CSE subjects and identifying areas to retain or update.
- Comparing curriculum topics with selected job descriptions.
- Examining credit information and identifying discrepancies requiring verification.
- Recommending improvements in areas such as AI, generative AI, data engineering, cloud computing, cybersecurity, and software testing.
- Mapping the Student Project Milestone Tracker capstone to relevant CSE subjects.
- Documenting AI-related exercises and example solutions.
- Developing an interactive webpage to present selected courses and recommendations.

### Interactive Curriculum Comparison

**Live webpage:** [Open the Curriculum Comparison](https://sanjanareddy3.github.io/Student-project-milestone-tracker/task-2/curriculum-comparison.html)

**Source file:** [`task-2/curriculum-comparison.html`](task-2/curriculum-comparison.html)

The webpage presents selected courses, preliminary credit information where available, KEEP/UPDATE recommendations, and suggested curriculum improvements.

### Curriculum Verification Note

The curriculum inventory and some credit details remain provisional until they are reconciled with the official curriculum applicable to the 2023 admission batch. Credit discrepancies are documented rather than resolved through assumptions. Proposed curriculum changes are recommendations, not official university changes.

The job-description analysis reflects the selected postings documented in the relevant file; it is not intended to represent every employer or role.
