## Important integrity note

The Task 1 workflow, volumes, timings and sample cases are assumptions for design and calculation. They are **not verified facts about ICFAI**. No campus observations, staff interviews or real student records are claimed. Use synthetic data only.

## Repository structure

- `task-1/` — HTML/CSS/JavaScript prototype, report and evidence templates.
- `task-2/` — planning placeholder for the curriculum audit/redesign task.
- `task-1/evidence/evidence-log.md` — evidence classification and access limitations.
- `task-1/evidence/test-results.md` — record actual results after running the prototype's five tests.

## Run Task 1 prototype

1. Open `task-1/student_milestone_tracker.html` in a modern browser such as Chrome.
2. Use the role selector to demonstrate the Student and Faculty Supervisor flows.
3. Create a synthetic milestone, submit it, and review/approve or request a revision.
4. Click **Run 5 test scenarios**.
5. Record what the test runner actually displays in `task-1/evidence/test-results.md`.

The role selector is only a demo. It is not authentication or production-grade access control. The application uses local browser storage; do not enter real personal, student or confidential college data.
