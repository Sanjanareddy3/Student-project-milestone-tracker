# Capstone Alignment — Student Project Milestone Tracker

## 1. Project Overview

The Student Project Milestone Tracker is a student-project management prototype. It provides a practical context for applying software engineering and computer science concepts to a real-world workflow.

Repository: https://github.com/Sanjanareddy3/Student-project-milestone-tracker

## 2. Curriculum Alignment

| Curriculum subject | Application to the project |
|---|---|
| Database Management System | Design tables for projects, milestones, submissions, and approvals. |
| Object Oriented Programming Concepts | Model projects, users, and milestone records using appropriate abstractions. |
| Web Enabled Technologies | Develop and improve the user interface and application interactions. |
| Software Engineering | Define requirements, document design decisions, and maintain the project repository. |
| Software Testing | Test valid submissions, missing information, duplicate submissions, and error recovery. |
| Artificial Intelligence | Explore optional AI-assisted milestone summaries or progress insights. |
| Big Data Systems | Explore importing and analyzing larger collections of milestone records. |
| Cloud Computing | Consider deployment and secure hosting as future extensions. |

These are proposed learning applications. They should not be treated as evidence that all these technologies have already been implemented.

## 3. Existing Prototype and Future Improvements

### Existing prototype

The current prototype supports manual browser testing of milestone-related scenarios, including valid submissions, missing information, duplicate submissions, unauthorized approval attempts, and error recovery.

### Proposed future improvements

1. Add persistent database storage.
2. Implement genuine user authentication and server-side role authorization.
3. Add automated unit and integration tests.
4. Record milestone status changes and approval history.
5. Build a dashboard for completion rates and overdue milestones.
6. Optionally add AI-generated progress summaries with human review.

## 4. Evaluation Plan

The project can be evaluated using:
- Functional correctness.
- Data integrity and validation.
- Authorization and security.
- Test coverage and reproducibility.
- Documentation and maintainability.
- Usefulness of any analytics features.
