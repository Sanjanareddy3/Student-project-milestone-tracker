# Curriculum Recommendations — 2030 Readiness

## 1. Evidence Base

This preliminary audit uses:
- The provided IFHE Hyderabad CSE curriculum screenshots.
- Three selected employer job descriptions documented in `job-description-analysis.md`.
- World Economic Forum, *Future of Jobs Report 2025*, which identifies AI and big data, networks and cybersecurity, and technological literacy as important growing skill areas.
- ACM, IEEE Computer Society, and AAAI, *Computer Science Curricula 2023*.
- NIST, *Artificial Intelligence Risk Management Framework: Generative Artificial Intelligence Profile* (26 July 2024).

Sources:
- WEF: https://www.weforum.org/publications/the-future-of-jobs-report-2025/
- CS2023: https://csed.acm.org/
- NIST: https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence

## 2. KEEP — Retain Core Foundations

| Course | Reason |
|---|---|
| Data Structures | Essential for problem-solving and efficient software. |
| Design and Analysis of Algorithms | Supports algorithmic thinking and performance analysis. |
| Operating Systems | Provides foundational knowledge of processes, memory, and system resources. |
| Database Management System | Directly supports SQL, relational data, and database design. |
| Computer Networks | Important for distributed systems, cloud services, and networking fundamentals. |
| Software Engineering | Supports software design, collaboration, and maintainable development. |

**Rationale:** These foundations remain relevant to modern computing and align with core areas in CS2023. Retention does not mean the course content must remain unchanged.

## 3. UPDATE — Modernize Practical Content

| Course | Proposed update | Reason |
|---|---|---|
| Computer Programming | Include Git, code review, debugging, and automated checks. | Practical software-development skills appear in early-career roles. |
| Database Management System | Add advanced SQL practice, query optimization, and data-quality checks. | SQL and reliable data are relevant to data-engineering work. |
| Artificial Intelligence | Include responsible AI, model evaluation, limitations, and bias awareness. | AI systems require evaluation and risk awareness. |
| Machine Learning | Strengthen data preparation, validation, experiment tracking, and deployment basics. | Model building should include reliable evaluation and practical application. |
| Big Data Systems | Include ETL/ELT pipelines, orchestration concepts, data validation, and distributed processing labs. | Relevant to data-engineering workflows. |
| Cloud Computing | Add hands-on deployment, access control, monitoring, and cost-awareness exercises. | Employers need practical experience beyond theory. |
| Software Testing | Include unit, integration, and API testing, plus CI workflows. | Testing and debugging are important software-development practices. |
| Industry Coding Practices | Use collaborative Git workflows, code reviews, and project documentation. | Supports team-based development. |

## 4. REDUCE — Conditional Recommendations Only

No existing course is recommended for removal at this stage.

Potential action: **REDUCE duplicated content within courses**, but only after comparing the detailed syllabi and identifying actual overlap.

The audit should not reduce mathematics, algorithms, operating systems, networking, security, or other core foundations solely because newer technologies are popular.

## 5. ADD — Proposed Learning Modules

These are proposed modules, not confirmed gaps in the current syllabus.

| Proposed module | Suggested delivery | Reason |
|---|---|---|
| Generative AI and RAG | Elective or integrated practical module | Covers LLM applications, retrieval, embeddings, and evaluation. |

## 6. Evidence-Based Justification

1. The WEF Future of Jobs Report 2025 identifies AI and big data, networks and cybersecurity, and technological literacy among the skills expected to grow in importance through 2030.
2. CS2023 provides a recognized reference for undergraduate computing knowledge areas, including AI, data management, security, software development, networking, and systems.
3. NIST's Generative AI Profile provides a framework for considering risks across generative-AI development and use.
4. The selected employer postings provide role-specific examples of programming, SQL, data pipelines, machine learning, Git, and testing requirements.
5. These sources support reviewing practical learning outcomes; they do not prove that the existing IFHE syllabus lacks a particular topic.

## 7. Credit-Balance Policy

- Do not change official course credits in the baseline inventory.
- Prefer updating labs and assignments within existing courses before adding credit-bearing subjects.
- If a new course is proposed, identify which elective or existing credit allocation it would replace.
- Calculate the original and proposed semester totals only after the complete curriculum, including electives, internships, and thesis/seminar components, has been transcribed and checked.

## 8. Link to the Student Project Milestone Tracker

The project can serve as a practical software-engineering capstone by incorporating:
- Database-backed milestone tracking.
- Role-based permissions and approval workflows.
- Input validation and duplicate detection.

These features are proposed extensions. They should not be described as implemented unless they are actually built and tested.
